# 眺刻 TiaoKe：GUI 与交互方案

## 1. 设计目标

界面关键词是“安静、清楚、有温度”。简洁不等于把所有内容压成一行，而是只保留当前决策需要的信息，并通过留白、字重、颜色和动态建立完整层级。

- 不打断：窗口出现时不抢焦点、不置于屏幕中央、不制造警报感。
- 一眼可读：时间是视觉主角，主要动作始终只有一个。
- 像 Windows 应用：使用 Segoe UI Variable、系统菜单语义和原生键盘行为。
- 有辨识度：以“地平线上的一点光”为品牌意象，但不使用装饰性插画。

## 2. 视觉系统

### 色彩

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| 页面背景 | `#F6F7F5` | `#171A18` | 设置页背景 |
| 浮层表面 | `#FFFFFF` | `#222624` | 提醒窗、菜单 |
| 主文字 | `#202522` | `#F1F4F2` | 标题、时间 |
| 次文字 | `#68716C` | `#AAB3AE` | 说明、单位 |
| 品牌绿 | `#2F765E` | `#70B99B` | 主按钮、进度 |
| 提醒黄 | `#D99A20` | `#E9B84A` | 到点状态的小面积提示 |
| 危险色 | `#B7473E` | `#EE8279` | 仅用于退出确认或错误 |

大面积只使用中性色，品牌绿用于交互，提醒黄只做 3 px 状态条或小图标。颜色不单独承担含义，必须同时配合文字或图标。

### 字体与尺寸

- 字体：`Segoe UI Variable Text`；数字使用等宽数字特性 `tnum`。
- 正文：14 px；辅助信息：12 px；页面标题：20 px；提醒主标题：18 px；倒计时：32 px。
- 字重只使用 400 与 500，不依赖超粗字制造层级。
- 文字不使用负字距，倒计时宽度固定，避免数字变化引起布局抖动。

### 形状与空间

- 圆角统一为 6 px 或 8 px，不使用胶囊形大按钮。
- 基础间距为 4 px，常用间距 8 / 12 / 16 / 24 px。
- 边框为 1 px 低对比中性色；提醒窗使用轻微系统阴影，不使用彩色辉光。
- 图标使用 Lucide 风格 16 px 线性图标；托盘图标单独绘制 16/20/24/32 px 像素适配版本。

## 3. 提醒窗口

默认停靠当前工作显示器左下角，与工作区边缘保持 16 px，尺寸为 `360 x 148 px`。窗口无系统标题栏，但保留可访问名称和键盘焦点边框；出现时保持 `Topmost`，不主动激活。

```text
┌────────────────────────────────────────────┐
│▌  该看看远处了                         ··· │
│   这一轮已经专注 20 分钟                    │
│                                            │
│   提醒会留在这里，不会打断你      [开始远眺] │
└────────────────────────────────────────────┘
```

- 左侧 3 px 提醒黄色状态条是唯一的强提示色。
- 右上角省略号打开轻量菜单：重置本轮、暂停提醒、打开设置。
- `开始远眺` 是唯一主按钮，使用品牌绿。窗口本身没有关闭按钮，避免“关闭”语义不明确。
- 用户继续工作时，提醒不闪烁、不重复出现、不播放声音。
- 点击提醒卡片空白处只激活窗口，不触发开始；主操作必须明确点击按钮。

出现动画为 160 ms：从下方平移 8 px 并渐入。关闭为 120 ms；系统开启“减少动态效果”时直接出现和消失。

## 4. 休息倒计时

点击开始后沿用同一位置和尺寸，内容就地切换，减少新的视觉打断。

```text
┌────────────────────────────────────────────┐
│   看向 6 米以外                             │
│                                            │
│   00:20   ━━━━━━━━━━━━━━━━━━━━━━━           │
│   放松眼睛，慢慢眨眼               [提前结束] │
└────────────────────────────────────────────┘
```

- 倒计时以 `MM:SS` 显示，进度条从满到空；不做循环动画。
- 最后 3 秒不变色、不发声，避免制造任务压力。
- `提前结束` 为低强调文字按钮；点击后仍视为完成休息并开始新一轮。
- 倒计时结束后显示“休息完成”约 800 ms，再自然退出并开始新的工作周期。

## 5. 设置窗口

设置窗口为 `700 x 520 px`，最小尺寸 `620 x 460 px`。它是一个完整工具窗口，不使用“卡片套卡片”。顶部是标题与三个页签，底部固定操作区；中间内容使用分隔线建立组别。

```text
┌──────────────────────────────────────────────────────────┐
│  眺刻设置                                            ─ □ ×│
│  [定时]  [行为]  [外观]                                 │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  工作与休息                                              │
│  工作时长                         [ 20  ▴▾ ] 分钟         │
│  休息时长                         [ 20  ▴▾ ] 秒           │
│  到点后保持提醒，直到你主动开始休息                      │
│  ──────────────────────────────────────────────────────  │
│  快捷设置                                                │
│  (●) 20 / 20     ( ) 30 / 30     ( ) 45 / 45            │
│                                                          │
├──────────────────────────────────────────────────────────┤
│                                  [恢复默认]  [保存更改]   │
└──────────────────────────────────────────────────────────┘
```

### 定时页

- 工作时长：数字步进输入，范围 1-180 分钟。
- 休息时长：数字步进输入，范围 5-300 秒。
- 快捷设置：20/20、30/30、45/45 单选项；选择后同步更新两个输入。
- 设置保存后默认从完整工作时长重新计时，并用一行非阻塞状态提示说明结果。

### 行为页

- `登录 Windows 后自动启动`：开关。
- `提醒时播放轻提示音`：开关，默认关闭；开启后提供试听图标按钮。
- `提醒位置`：四角位置选择器，默认左下角。
- `在哪块屏幕显示`：下拉菜单，选项为当前活动窗口所在屏幕 / 主屏幕。
- `暂停结束后`：下拉菜单，默认“开始新一轮”。

### 外观页

- 主题：跟随系统 / 浅色 / 深色，使用三段式选择。
- 紧凑提醒：开关；开启后隐藏说明行，窗口高度缩至 112 px。
- 显示预览：在页面右侧或下方按可用宽度展示真实比例提醒窗，不再套额外卡片边框。

## 6. 托盘体验

托盘图标以一条地平线和上方圆点构成，在 16 px 下仍能识别。正常状态为单色；到点时圆点变为提醒黄色，但不闪烁。

右键菜单使用 Windows 原生菜单尺寸与选中态，不做重皮肤。状态行不可点击并采用次文字色；危险操作“退出眺刻”放在末尾，不使用红色常驻强调。

托盘菜单的时间每秒更新没有实际价值，因此只在菜单打开时计算并显示到秒，关闭时停止界面刷新，降低无意义唤醒。

## 7. 文案规范

| 场景 | 文案 |
| --- | --- |
| 到点标题 | `该看看远处了` |
| 到点说明 | `这一轮已经专注 {n} 分钟` |
| 持续提示 | `提醒会留在这里，不会打断你` |
| 主按钮 | `开始远眺` |
| 休息标题 | `看向 6 米以外` |
| 休息辅助 | `放松眼睛，慢慢眨眼` |
| 完成 | `休息完成` |
| 暂停状态 | `已暂停至 {HH:mm}` |

文案避免命令式的“必须休息”“不要跳过”和评价式的“今天做得不够好”。

## 8. 响应与可访问性

- 所有操作支持键盘；`Enter` 执行主操作，`Esc` 仅关闭设置页，不关闭持续提醒。
- 点击目标不小于 32 x 32 px；触摸场景有效命中区不小于 44 x 44 px。
- 主文字与背景至少满足 WCAG AA；焦点边框在浅色和深色主题均清楚可见。
- 屏幕阅读器播报状态变化，但不每秒播报倒计时；只播报开始、剩余 10 秒和完成。
- 200% 缩放时提醒窗口按内容扩展高度，按钮允许换行，不裁切中文或数字。
- Windows 高对比度模式下退回系统颜色，不依赖自定义背景图。

## 9. 设计验收

- 提醒出现时，正在输入的编辑器仍保持焦点。
- `360 x 148 px` 内最长中文文案和主按钮不重叠；200% 缩放下自动增高。
- 浅色、深色、高对比度下层级一致，不存在低对比文字。
- 四种任务栏位置、四角提醒位置和多显示器组合均不越出工作区。
- 所有动态效果可关闭，倒计时更新不会导致窗口尺寸或元素位置抖动。
