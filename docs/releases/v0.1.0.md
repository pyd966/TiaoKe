# 眺刻 TiaoKe v0.1.0

这是眺刻的第一个公开版本：一款安静、不强制的 Windows 远眺休息提醒工具。

## 主要功能

- 默认采用 20 分钟工作、20 秒远眺的节奏，也可选择 10/20、30/120 或自定义时间。
- 到点提醒停靠屏幕角落，不抢焦点、不锁屏，等待用户主动开始休息。
- 支持立即休息、提前结束、重置本轮，以及暂停提醒 15/30/60/120 分钟或当天不再提醒。
- 托盘菜单实时显示剩余时间，支持圆角、悬停高亮和浅色/深色主题。
- 提供应用专属的休息提醒音与休息完成音，可在设置中关闭。
- 支持提醒角落、目标显示器、紧凑提醒、跟随系统主题和登录后自动启动。
- 设置仅保存在本机，不需要账号或网络连接。

## 下载

- **单文件版**：下载 `TiaoKe-v0.1.0-win-x64.exe` 后直接运行。
- **便携压缩包**：下载并解压 `TiaoKe-v0.1.0-win-x64.zip`，运行其中的 `TiaoKe.exe`。
- **完整性校验**：使用 `TiaoKe-v0.1.0-SHA256.txt` 核对下载文件。

## 系统要求

- Windows 10 22H2 或更高版本 / Windows 11
- x64 处理器
- 无需另行安装 .NET

> 当前版本没有商业代码签名。Windows 首次运行时可能显示 SmartScreen 提示，请确认文件来自本仓库的 Releases 页面并核对 SHA-256 后再运行。
