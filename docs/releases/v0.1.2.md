# 眺刻 TiaoKe v0.1.2

这是一次多桌面支持更新。

## 本次更新

- Windows 多桌面环境下，提醒卡片会自动显示在所有虚拟桌面。
- 使用 Windows Shell 的虚拟桌面固定机制，不复制多个提醒窗口，也不改变原有提醒位置。
- 虚拟桌面接口初始化失败时自动回退到当前桌面，不影响计时和提醒功能。
- 保留原有托盘菜单、圆角操作菜单、主题、提示音和暂停休息功能。

## 下载

- **单文件版**：下载 `TiaoKe-v0.1.2-win-x64.exe` 后直接运行。
- **便携压缩包**：下载并解压 `TiaoKe-v0.1.2-win-x64.zip`，运行其中的 `TiaoKe.exe`。
- **完整性校验**：使用 `TiaoKe-v0.1.2-SHA256.txt` 核对下载文件。

## 系统要求

- Windows 10 22H2 或更高版本 / Windows 11
- x64 处理器
- 无需另行安装 .NET

> 当前版本没有商业代码签名。Windows 首次运行时可能显示 SmartScreen 提示，请确认文件来自本仓库的 Releases 页面并核对 SHA-256 后再运行。
