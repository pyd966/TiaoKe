# 眺刻 TiaoKe v0.1.1

这是一次界面修复更新，重点改善休息提醒卡片右上角“三点”操作菜单。

## 本次更新

- 重新设计提醒卡片的操作菜单，使其与眺刻的整体界面风格保持一致。
- 为菜单、菜单项和“暂停休息提醒”子菜单加入圆角设计。
- 修复部分主题组合下白色文字与白色背景重叠、内容无法辨认的问题。
- 菜单颜色现在会随浅色、深色和系统主题正确变化。
- 增加清晰的品牌色悬停高亮，并统一字体、间距、分隔线和子菜单箭头。

## 下载

- **单文件版**：下载 `TiaoKe-v0.1.1-win-x64.exe` 后直接运行。
- **便携压缩包**：下载并解压 `TiaoKe-v0.1.1-win-x64.zip`，运行其中的 `TiaoKe.exe`。
- **完整性校验**：使用 `TiaoKe-v0.1.1-SHA256.txt` 核对下载文件。

## 系统要求

- Windows 10 22H2 或更高版本 / Windows 11
- x64 处理器
- 无需另行安装 .NET

> 当前版本没有商业代码签名。Windows 首次运行时可能显示 SmartScreen 提示，请确认文件来自本仓库的 Releases 页面并核对 SHA-256 后再运行。
